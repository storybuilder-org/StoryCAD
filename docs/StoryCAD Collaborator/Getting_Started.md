# Getting Started

This page covers install and setup. When Collaborator is running, see [Opening Collaborator](Opening_Collaborator.html) for the window layout and [Running a Workflow](Running_a_Workflow.html) for your first craft job.

## What you need

1. **StoryCAD** installed on Windows or macOS. Collaborator is a plug-in; it does not replace StoryCAD.
2. A store account on the platform you use (Microsoft account for the Microsoft Store, Apple ID for the App Store).
3. An open story outline in StoryCAD when you launch Collaborator. The plug-in works on the outline you have open.

StoryCAD Collaborator is a **paid plug-in**. A **free trial** is available so you can try it before you buy. You can download it from the **Microsoft Store** and the **Apple App Store**. The store listing shows trial length and current terms; this manual does not discuss pricing.

## Install on Windows

1. Install **StoryCAD** from the Microsoft Store if you have not already.
2. Open the Microsoft Store and find **StoryCAD Collaborator** (or open its store link from StoryBuilder.org if you have one).
3. Install the plug-in.
4. Start StoryCAD, open or create an outline, then start Collaborator from StoryCAD (toolbar or menu, depending on your version).

If Collaborator does not appear, restart StoryCAD after install and confirm both apps are from the Store on the same machine.

## Install on Mac

1. Install **StoryCAD** from the Apple App Store if you have not already.
2. Open the App Store and find **StoryCAD Collaborator**.
3. Install the plug-in.
4. Start StoryCAD, open or create an outline, then start Collaborator from StoryCAD.

Mac and Windows share the same idea: StoryCAD holds the outline; Collaborator is the helper window.

## First-time setup

After install, the first launch may ask you to sign in or activate so Collaborator can run its workflows. Follow the on-screen steps. You need a working network connection.

If you are in a **beta** or classroom program, your host may give extra steps (for example, how you were invited). Use those instructions when they differ from the public store path.

## Preferences that affect the manual

StoryCAD can open the **production** or **beta** user manual from Help, depending on your build and the **Use beta documentation** preference. Collaborator’s own help points at the same manual family. Use the beta manual while features are still landing; switch when your host or release notes say the production manual is current.

## Check that it works

1. Open StoryCAD and an outline that has at least a short **Story Idea** on the Overview.
2. Launch Collaborator.
3. Select a simple workflow such as **Premise** (the list may show a longer ideation label).
4. When suggestions appear, you are set. See [Reviewing Suggestions](Reviewing_Suggestions.html) before you accept anything you care about.

If the window never opens, reinstall from the store and restart StoryCAD. For StoryCAD help in general, see [Getting Help](../Front%20Matter/Getting_Help.html).
