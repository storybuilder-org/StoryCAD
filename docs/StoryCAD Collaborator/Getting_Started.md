# Getting Started

This page covers what you need and how to switch Collaborator on. When it is running, see [Opening Collaborator](Opening_Collaborator.html) for the window layout and [Running a Workflow](Running_a_Workflow.html) for your first workflow.

## What you need

1. **StoryCAD** on Windows or macOS. Collaborator is part of StoryCAD, not a replacement for it.
2. An open story outline. Collaborator works on the outline you have open.
3. A working network connection. Workflows run against a service, so they need one.

StoryCAD Collaborator is a **paid** feature with a **free trial**. There is nothing separate to download or install.

## Turn it on

1. Open StoryCAD and open or create an outline.
2. Click **Collaborator** on the toolbar.
3. You are offered a subscription or a free trial. Choose **Subscribe**, or **Restore purchases** if you have paid before.
4. Collaborator opens in its own **Story Collaborator** window.

The dialog shows the trial length and current price for your store. This manual does not discuss pricing.

![StoryCAD toolbar; the Collaborator button is the highlighted chain icon](../media/Collaborator-Toolbar-Button.png)

The prompt is the same on both platforms; only the store behind it differs, the Microsoft Store on Windows and the App Store on Mac.

<!-- image: subscribe or start trial prompt -->

## Preferences that affect the manual

StoryCAD can open the **production** or **beta** user manual from Help, depending on your build and the **Use beta documentation** preference. Collaborator's own Help points at the same manual. Use the beta manual while features are still landing; switch when your host or release notes say the production manual is current.

## Check that it works

1. Open an outline that has at least a short **Story Idea** on the Overview.
2. Launch Collaborator.
3. Select a simple workflow such as **Premise** (the list may show a longer ideation label).
4. When suggestions appear, you are set. See [Reviewing Suggestions](Reviewing_Suggestions.html) before you accept anything you care about.

If the window never opens, restart StoryCAD. For StoryCAD help in general, see [Getting Help](../Front%20Matter/Getting_Help.html).
