# Tutorial

Two ways to learn Collaborator by using it.

[A Path to Try](A_Path_to_Try.html) is an order of workflows to run: which workflow first, which next, and why that order wastes less of your time.

[An Example Session](An_Example_Session.html) walks one short sitting end to end, from a first workflow run to accepted text in your outline.

Read the path first if you want the shape of the work. Start with the session if you would rather follow along at the keyboard.
