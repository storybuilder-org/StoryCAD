# Tutorial

These two pages teach Collaborator by using it. [A Path to Try](A_Path_to_Try.html) is an order of workflows to run: which workflow first, which next, and why that order wastes less of your time. [An Example Session](An_Example_Session.html) walks one short sitting from end to end, from a first workflow run to accepted text in your outline, on a sample story that ships with StoryCAD.

Read the path first if you want the shape of the work before you begin. Start with the session if you would rather follow along at the keyboard.
