# Tips and Common Questions

## Start with something on the Overview

A blank outline gives Collaborator little to stand on. One honest sentence under Story Idea is enough to begin. More context (concept, premise, a named protagonist) usually improves later jobs.

## Re-running a workflow

Second passes are normal. Expect many fields to show **has your text** if you already accepted a first pass. Use Review Each when you want a deliberate replace; use Accept All only for fields that are still ready.

## Long lists of updates

Some jobs propose many fields at once. Scroll the Property Updates list, or use Review Each so you do not miss rows below the fold. If the list is hard to use in your build, fall back to Review Each for trust.

## Save often enough

Accept, then Save, then glance at StoryCAD. That three-step habit catches surprises early.

## Connection and access

Collaborator needs a working network connection to run workflows. Install it from the Microsoft Store or Apple App Store as a paid plug-in for StoryCAD. If a beta host gave you special access steps, follow those; they are not covered here.

## Getting help

Use Collaborator’s **Help** control for a short in-app overview. For StoryCAD itself, see [Getting Help](../Front%20Matter/Getting_Help.html) in this manual. For product feedback during beta, use the channel your host names (email, forum, or in-app feedback).

## Common questions

**Will Collaborator change my outline without asking?**  
No. Suggestions stay pending until you accept them.

**Why didn’t Accept All change a field I care about?**  
That field likely already had your text. Use Review Each and Accept if you want the new version.

**Can I use Collaborator instead of learning structure?**  
You can try. You will get better results, and better books, if you learn the craft the workflows point at.

**Do I need every workflow?**  
No. Follow [A Path to Try](A_Path_to_Try.html) until those jobs feel solid.
