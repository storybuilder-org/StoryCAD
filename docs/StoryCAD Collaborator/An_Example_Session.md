# An Example Session

This walkthrough is short enough for a class period or a first evening with Collaborator. Use any thin outline. A one-line story idea on the Overview is enough to start.

The story here is only an example: *a systems engineer who must stop a predictive defense AI from “collapsing” reality into a forced win.*

<!-- image: Overview with a short Story Idea filled in -->

## 1. Start

1. Open StoryCAD and create or open an outline.  
2. On **Story Overview**, enter at least a short **Story Idea** (and a **Concept** if you have one).  
3. Open **StoryCAD Collaborator**.

You now have something for Collaborator to read. Empty forms produce empty-sounding help.

## 2. Premise

1. Select the **Premise** workflow (the list may show a longer ideation label; the job is premise).  
2. Let it run.  
3. Open **Property Updates**.  
4. Use **Accept All** if the Overview fields were empty. If some fields already had your text, either **Review Each** or leave them.

Return to StoryCAD and open Overview. Premise (and related fields you accepted) should show the new wording.

<!-- image: Property Updates after Premise -->

**Craft check:** Does the premise name a protagonist, a goal, and opposition? If not, edit it yourself or Try Again. See [Story Idea, Concept, and Premise](../Writing%20with%20StoryCAD/Story_Idea_Concept_and_Premise.html).

## 3. Story Problem

1. Run **Story Problem**.  
2. If asked to create or pick characters, do so.  
3. Accept the problem name and core fields you want. Skip anything that feels wrong.

You should have a main problem linked as the story problem, with protagonist and antagonist placeholders or names.

<!-- image: Story Problem results or Problem form after accept -->

## 4. GMC

1. Run **Goal / Motivation / Conflict (GMC)** on that problem.  
2. If many fields already have text from an earlier pass, note which updates are **ready** and which **have your text**.  
3. Use **Review Each** on at least one “has your text” field. Read **Yours** vs **Proposed**. Accept or Skip deliberately.  
4. Use **Accept Free Remaining** or **Accept All** for the ready fields.

<!-- image: Review Each on one GMC field -->

**Craft check:** Can you state what the protagonist wants, why, and what opposes them? Same for the antagonist? See [Defining Problems](../Writing%20with%20StoryCAD/Defining_Problems.html).

## 5. Optional next beat

If you have time, run **Inner and Outer Problems** or one character workflow (Role, Flaw, or Backstory) on the protagonist. One more job is enough for a first session.

## 6. Close the loop

1. **Save** in Collaborator if you have not already.  
2. **Exit** Collaborator.  
3. In StoryCAD, click the Problem and Character elements and confirm the accepted text is there.

That is a full loop: craft job → suggestions → your judgment → outline updated.

## What students should notice

- You stayed in charge.  
- Empty fields are easy to fill in bulk; filled fields demand a look.  
- One workflow equals one craft question, not “write my book.”  
- Chat is optional; the example above never required it.
