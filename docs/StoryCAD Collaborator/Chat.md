# Chat

The right-hand column is **chat**. After a workflow runs, Collaborator posts status there (what finished, how many updates are waiting). You can also type questions.

## Good uses of chat

- “Give me three tighter versions of that premise line.”  
- “Explain why you chose this antagonist goal.”  
- “Make the conflict more personal, less abstract.”

Use chat to explore. Then, if you want text in a field, run a workflow again or copy wording into StoryCAD yourself and accept formal Property Updates when the workflow offers them.

<!-- image: chat column with a short Q and A after a run -->

## What chat does not do

Chat is conversation. It does **not** replace the Accept path for structured field updates.

If you only chat and never accept Property Updates, the outline fields stay as they were. That is intentional.

## When to prefer a workflow over chat

| Need | Prefer |
|------|--------|
| Fill several named fields on a form | A **workflow** |
| One-off rephrase or explanation | **Chat** |
| Re-run the same craft job cleanly | **Try Again** on the workflow |

Workflows know which fields belong to which story element. Chat is freer and less structured. Use both, but do not expect chat alone to rebuild your outline.
